# UI tells

Ids are stable, and reports cite them. **(L)** marks the tells `scripts/scan.mjs` can find; **(T)** marks the ones `scripts/tokens.mjs` measures. Everything else needs eyes on a screenshot or the markup.

## Template tells

These are taste calls. Each is a default that shows up regardless of subject. Any of them is fine when the brief asks for it. When nothing in the brief chose it, it is a tell.

- **ui-1 Default gradients (L).** Purple, indigo, or violet washes into blue or pink, and gradient text on one headline word. Fix: a palette drawn from the subject. Flat color unless a gradient carries meaning.
- **ui-2 Hero formula.** Centered headline with one accented word, a subhead, a primary button plus "Learn more", and a "Trusted by" logo strip. Fix: open with the most characteristic thing in the subject's world, such as the product itself, a real screenshot, or a live demo.
- **ui-3 Card-grid sameness.** Everything chopped into identical rounded cards, including the 3-up feature grid of icon-in-tinted-circle, title, and two lines. Fix: vary the form by content. Use a list for a list, a table for comparison, and prose for an argument.
- **ui-4 One radius, one shadow (T).** The same `rounded-2xl` and `shadow-lg` on every element regardless of hierarchy. Fix: radius and elevation that encode hierarchy, from a small defined set.
- **ui-5 Glass and glow (L).** Backdrop-blur panels, blurred color blobs, neon glow shadows used as decoration. Fix: remove them; use solid surfaces.
- **ui-6 Stock icons as content (L).** Sparkles, Zap, Rocket, and Shield icons, or emoji, standing in for feature illustrations. The scanner reports emoji once per file with the count. Fix: real product imagery, or no icon.
- **ui-7 Template chrome (L).** A "✨ New" pill above the hero, tracked-out ALL-CAPS eyebrows over every heading, numbered 01/02/03 markers on things that aren't a sequence, `A · B · C` meta strings, `→` appended to every link. Fix: keep only the chrome that encodes information. The scanner reports middle dots once per file and skips page titles ("Docs · Product"); in an app, `·` between data values ("12 players · 3 min") is information, not chrome. It reports zero-padded section numbers once per file, from two up; a single "01" is a label, three in a row over features is numbering with no order behind it.
- **ui-8 Fabricated proof (L).** "10K+ users", "99.9% uptime", invented testimonials, placeholder logos. Fix: real numbers with sources. If the numbers don't exist, cut the section.
- **ui-9 Default type.** One system or Inter family at default weights with no deliberate scale, or sizes picked ad hoc. Fix: a chosen family (two at most) and a stated scale.
- **ui-10 Studio defaults.** Cream background with a serif display and a terracotta accent; near-black with one acid-green accent; newspaper hairlines with zero radius. Fix: the same as ui-1, choose for the subject.
- **ui-11 Motion everywhere (L).** Fade-up on every section, hover-lift on every card, pulsing badges, `transition-all`. A pulsing skeleton is the loading affordance, not a tell. Fix: one deliberate moment, plus motion that answers a user action.
- **ui-12 Symmetric sameness.** Everything centered, every section the same width and padding, image and text alternating sides. Fix: hierarchy, meaning a clear primary element per screen and spacing that groups related things.
- **ui-22 Badge and tag clutter (L).** A pill, chip, or tag on every card, heading, and list row: "New", "Beta", "Pro", category labels nobody filters by. The scanner reports a file from three small rounded-full labels or `<Badge>` elements up. Fix: a tag only where the reader sorts or filters by it. Status that matters goes in words.
- **ui-23 Decorative emphasis (L).** One italic word in a headline, usually in a serif, with nothing in the sentence that calls for stress. The scanner finds `<em>` or an italic span inside `h1` to `h3`, and `italic` next to a serif or display font class. Fix: set the headline in one style. Italic is for stress, titles, and foreign words.
- **ui-24 Display-serif defaults (L).** Instrument Serif, Playfair Display, Fraunces, DM Serif, Cormorant, or Newsreader as the display face, tightened with negative tracking (`tracking-tighter`, `letter-spacing: -0.04em`). It is the 2024 template look as much as the purple gradient was the 2022 one. Fix: a face chosen for the subject, at its designed spacing. Negative tracking stays where the face is set large and the designer tuned it, which a per-heading utility class rarely is.
- **ui-25 Dividers everywhere (L).** An `<hr>`, `<Separator>`, or `divide-y` between every pair of blocks, often with a border on each block as well. The scanner reports a file from three up. Fix: let spacing separate. Keep a rule only where two groups would read as one without it.
- **ui-27 Bordered boxes everywhere (L).** Every block wrapped in `border rounded-xl p-6`, or `ring-1 ring-white/10`, so the page is a grid of outlined containers. The dark-mode version is the "glass panel" of ui-5. The scanner reports a file from five bordered, rounded, padded blocks up. Fix: boxes only around things that are objects (a card the user picks, a form). Sections, lists, and prose sit on the page.
- **ui-28 Decorative diagrams.** Node-and-edge graphs, orbiting logos, "architecture" illustrations, animated connection lines, and fake dashboards built from rectangles, placed to look technical. The more detail they carry, the less they say, because none of it is the product. The scanner flags an inline SVG from twelve shapes up as a candidate. Fix: a real screenshot, a real diagram with labels the reader needs, or nothing.
- **ui-29 Code breadcrumbs (L).** File paths (`src/components/Hero.tsx`), `~/` prompts, `$ npm install` lines, and `font-mono` labels used as decoration in a product that isn't a developer tool, or on a page that isn't documentation. Fix: remove them. A docs page shows the path of the file it is documenting and nothing else. The scanner skips `docs/` folders.
- **ui-30 Detail for its own sake.** Micro-labels on every element, four font sizes in one card, avatars, counters, status dots, and tooltips stacked on a hero, nested panels with their own headers. It reads as rich at a glance and as noise on use. Fix: one piece of information per element. Cut each decoration that the user never reads.

## Craft tells

These are bugs. Fix them without asking.

- **ui-13 Token sprawl (L, T).** Near-duplicate colors and grays, many radii, shadows, or font sizes; raw values that bypass existing tokens; arbitrary values (`mt-[13px]`, `bg-[#5b5bd6]`). The scanner reports arbitrary values once per file with the count; `tokens.mjs` lists the distinct values. Fix: map every value onto the project's scale. Extend the scale only for a real gap.
- **ui-26 Opacity and shade stacks (L, T).** `bg-white/5`, `border-white/10`, `text-white/60`, `ring-white/20`, and `rgba(255,255,255,0.08)` as a substitute for a palette, or `zinc-300`, `-400`, and `-500` on neighboring lines. Each is a mix the reader can't name, and the UI ends up with fifteen grays. The scanner reports a file from four distinct opacity levels up, and `tokens.mjs` lists them. Fix: named surface and text tokens on the scale, and one opacity for disabled states.
- **ui-14 Missing states.** Only the happy path exists. Empty, loading, error, disabled, and long-content states are missing. Fix: design each state. An empty state tells the user what to do next.
- **ui-15 Contrast (L).** Body text below 4.5:1 (large text below 3:1), such as light gray on white or a placeholder used as the label. `dark:` variants are judged against the dark background. Fix: darken to pass WCAG AA, and use visible labels.
- **ui-16 Focus removed (L).** `outline-none` (`outline-hidden` in Tailwind v4) or `outline: none` with no visible replacement nearby (a `focus-visible:` ring, or a `data-highlighted:` state on menu items), or interactions reachable only by mouse or hover. Fix: a visible `:focus-visible` style and a working keyboard path.
- **ui-17 Semantics (L).** Clickable `div`s (React `onClick`, Svelte `onclick` and `on:click`, Vue `@click`), `img` without `alt` (Svelte's `{alt}` shorthand and a props spread count as an `alt`), icon-only buttons without an accessible name, skipped heading levels, links styled as buttons that act as buttons. Fix: the native element with its name.
- **ui-18 Responsiveness.** Fixed widths, horizontal scroll at 375px, hover-only affordances, tap targets under 24px. Fix: fluid layout checked at mobile width, with targets of at least 24px (44px preferred).
- **ui-19 Reduced motion ignored (L, T).** Animation with no `prefers-reduced-motion` path. The scanner judges each file; a global rule in the base stylesheet clears every hit, and `tokens.mjs` lists which files handle it. A spinner is essential motion and is skipped. Fix: disable or shorten non-essential motion under it.
- **ui-20 Copy slop (L).** "Unlock", "Supercharge", "Elevate your workflow"; vague CTAs ("Get started", "Learn more", "Submit"); "Oops! Something went wrong"; an action renamed mid-flow. Fix: name things from the user's side. A button names its exact action ("Save changes"), the same action keeps the same name through the flow, and an error says what happened and how to fix it. Run `unslop-text` on all copy.
- **ui-21 Placeholder residue (L).** Lorem ipsum, "John Doe", "Acme", example.com, `placehold.co` images, "Feature 1/2/3". An input's `placeholder="you@example.com"` is a format hint, not residue. Fix: real content from the project, or ask.
