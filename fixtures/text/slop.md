# Getting Started With The Toolkit 🚀

In today's fast-paced world, developer tooling plays a pivotal role in shipping software. In this guide, we'll explore how the toolkit serves as a seamless bridge between your code and production — ensuring a smooth experience.

It's not just a CLI, but a complete platform. Whether you're a beginner or an expert, you'll love it.

- **Performance:** Performance is blazing fast.
- **Safety:** Safety is built in.

Let's dive in! No config. No boilerplate. Just code.

```bash
npm install toolkit -- --delve
```

In order to configure it, you could potentially edit `robust.config.js`.

I hope this helps! Happy coding!
